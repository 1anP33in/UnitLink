# Shared Tools

{% hint style="warning" %}
Preview mockup. It isn't in the game yet.
{% endhint %}

These are built once and shared by every department, not rebuilt for each one.

| Feature | What it does |
|---|---|
| **Global search** | Search people, vehicles, calls and reports across departments. Results follow each department's record access |
| **Live notifications** | Real-time dispatch updates, with a bell and a feed |
| **Unit messaging** | All-units, department and direct channels between on-duty units |
| **Activity logs** | Every employee action, filterable by department |
| **BOLO system** | BOLOs for one department or all of them |
| **Incident linking** | Several departments' calls joined into one incident (for example LEO + SAFR + DOT at a crash) |
| **GPS integration** | Route to calls and work orders |
| **Employee profiles** | Departments, ranks, callsigns, certifications and activity |
| **Audit history** | Every administrative change |
| **Permission engine** | Access controlled by rank and department, with extra permissions from sub-departments |
