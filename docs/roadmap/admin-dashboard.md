# Admin Dashboard

{% hint style="warning" %}
Preview mockup. It isn't in the game yet.
{% endhint %}

A separate admin area for authorized administrators only. Everything in it is **set from the dashboard, not code**: changes apply to the CADs straight away and are written to the audit history.

## Department manager
* Create, delete and rename departments, and set their abbreviations.
* Upload a logo and pick a color.
* Turn departments on or off.
* Choose which call types each one receives (Police, Fire, Medical, DOT).
* Choose whether each one can open the CAD, and its visibility (public, internal, hidden).
* Each department uses a template (Police CAD, Fire & Rescue CAD or DOT Work Orders), and a new department shows up in the department list straight away.

## Sub-department manager
For example, under **Department of Transportation**: Highway Maintenance, Road Construction, Traffic Operations, Towing & Recovery and Roadside Assistance.
* Create, remove, and turn sub-departments on or off.
* Assign employees.
* Give each one its own ranks, permissions, callsign format and unit statuses.

## Ranks & permissions
* Create, delete, rename and reorder ranks.
* A permission grid per rank: supervisor, approve warrants, Signal 100, announcements, manage roster, edit and delete records, view medical records, close calls and jobs.

## Employee manager
Search employees, create accounts, put one person in several departments, assign ranks and callsigns, suspend accounts, remove access and review each person's activity.

## System configuration
Call types, priorities (label and color), unit statuses, citation points for each offense, license point limits (suspend and revoke), report rules (minimum narrative length, must link to a call), notification settings, and which departments can see which records (criminal, citations, medical, work orders, civil).

## Audit history
Every admin change, with who made it and when.
