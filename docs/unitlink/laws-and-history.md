# Laws & Call History

## Laws

The Tropical State code, from `config.lua`. You can search it by code, offense or abbreviation.

| Color | Class |
|---|---|
| Red | **F**: Felony |
| Yellow | **M**: Misdemeanor |
| Green | **I**: Infraction |

The **License Points** column shows what a citation adds. To change the laws, see [Editing the Laws](../configuration/laws.md).

## Call History

The last **100 closed calls**. Each shows the nature, priority, address, caller, units, when it was opened and closed, and the disposition. Click one to open it read-only.
