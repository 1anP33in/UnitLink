# Name Search & State Returns

1. Open **Search**.
2. Type a **name** or **character ID** (at least 2 characters), then click **Run Name**.
3. Click a result to run the **state return**.

## The state return

The return is printed in the green-on-black terminal style. It shows:

* **Identity:** name, character ID, date of birth and age, sex, height, nationality.
* **Licenses:** driver's (with points out of 12), firearm, pilot.
* **Wants / warrants:** shows a red **WARNING: SUBJECT IS WANTED** banner when there's an active warrant.
* **Alerts** linked to the person.
* **History:** number of citations, arrests and reports, plus the last 10 records.

## From a return you can

* **Issue Citation**, **Arrest Report** or **Incident Report**
* **Request Warrant**
* **Add Alert** linked to the person

The person is filled in on the form for you.

## Returns log

**Returns** lists every name you ran in the last 12 hours. Click one to run it again. Names you run while attached to a call also show on that call's **State Returns** tab.

{% hint style="info" %}
Nothing private is sent to the tablet: no account identifiers, only what the CAD shows.
{% endhint %}
